Возможности клиента

📜

Скриптовый API

Создавайте собственные клиентские модули на JavaScript, Java или Kotlin без перекомпиляции мода. Горячая перезагрузка скриптов прямо в игре.

🎯

Категории модулей

Шесть встроенных категорий: Combat, Movement, Player, Visuals, UI и Misc. Организуйте свои модули по назначению.

🖼️

HUD-элементы

Рисуйте текст, прямоугольники и изображения на экране. Поддержка перетаскивания мышью и сохранение позиций.

⚙️

Гибкие настройки

Переключатели, числовые поля, выбор режима, мульти-переключатели и цветовые настройки для каждого модуля.

⌨️

Клавиши биндов

Назначайте клавиши для быстрого переключения модулей прямо из карточки настроек в меню.

🔄

Hot Reload

Изменения в .js, .java или .kt файлах подхватываются автоматически без перезапуска клиента.

Категории модулей

Combat

Бой

Модули для автоматизации боя, атаки, критов и взаимодействия с сущностями.

Movement

Движение

Модули для управления передвижением: спринт, полёт, скорость, прыжки.

Player

Игрок

Информация о локальном игроке, здоровье, сытость, эффекты, инвентарь.

Visuals

Визуал

Изменение отображения мира, подсветка сущностей, HUD-индикаторы.

UI

Интерфейс

Кастомные элементы интерфейса, меню, оверлеи и уведомления.

Misc

Разное

Вспомогательные модули, которые не подходят под остальные категории.

Быстрый старт

  1. Установите Fabric API и загрузите сборку ModuleDLC через модменеджер.
  2. Запустите Minecraft один раз, чтобы создать папку конфигурации.
  3. Положите скрипты в .minecraft/config/moduledlc/scripts/.
  4. Откройте меню ModuleDLC в игре, включите нужный модуль и настройте его.
hello.js
var hello = api.module(
    "hello",
    "Hello",
    "Misc",
    "Пример модуля"
);

hello.onEnable(function (ctx) {
    ctx.message("Модуль включён!");
});

hello.register();
