ModuleDLC Script API

ModuleDLC — клиентский мод для Minecraft, который позволяет создавать и настраивать собственные модули на JavaScript, Java и Kotlin. Добавляй настройки, бинды и HUD-элементы, а изменения скриптов проверяй прямо в игре благодаря горячей перезагрузке.

Каждый скрипт регистрирует модуль через api.module(id, name, category). Модули появляются в меню по категориям; их можно включать, настраивать и привязывать к клавишам.

ModuleDLC — Minecraft настраивается под тебя.
Допустимые категории: Combat, Movement, Player, Visuals, UI, Misc. Если указать другую, модуль не зарегистрируется.

Быстрый старт

Скрипты загружаются из:

.minecraft/config/moduledlc/scripts/

При первом запуске ModuleDLC создаёт эту папку. В development-запуске это обычно run/config/moduledlc/scripts/.

Пример модуля (JavaScript)

var hello = api.module(
    "hello",
    "Hello",
    "Misc",
    "Пример пользовательского модуля"
);

hello.onEnable(function (ctx) {
    ctx.message("Модуль включён");
});

hello.onTick(function (ctx) {
    if (!ctx.inGame()) return;
    // Здесь можно читать локального игрока и мир.
});

hello.register();

После успешной загрузки модуль появится в категории Misc. Откройте меню ModuleDLC и включите его.

api.module

Создаёт и возвращаетビルдер модуля:

api.module(id, name, category, description?)
ПараметрТипОписание
idStringУникальный идентификатор модуля
nameStringОтображаемое имя в меню
categoryStringОдна из: Combat, Movement, Player, Visuals, UI, Misc
descriptionStringОписание (опционально)

id должен быть уникальным среди всех загруженных модулей. name и category не должны быть пустыми.

Callbacks модуля

Все callbacks получают ScriptContext и выполняются клиентской логикой ModuleDLC:

CallbackКогда вызывается
onEnable(ctx)При включении модуля пользователем
onDisable(ctx)При выключении, выгрузке или ошибке в callback
onTick(ctx)Каждый клиентский тик, пока модуль включён
onFrame(ctx)Каждый кадр, пока модуль включён

Используйте onDisable для отмены временных изменений (например, сброса спринта). Если callback выбрасывает исключение, модуль отключается с пометкой (error).
