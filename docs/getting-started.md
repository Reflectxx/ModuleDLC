# Быстрый старт

## 1. Найдите папку скриптов

Скрипты загружаются из:

```text
.minecraft/config/moduledlc/scripts/
```

При первом запуске ModuleDLC создаёт эту папку. В development-запуске из
проекта это обычно `run/config/moduledlc/scripts/`.

## 2. Создайте JavaScript-модуль

Создайте `hello.js` в папке скриптов:

```javascript
var hello = api.module(
    "hello",
    "Hello",
    "Misc",
    "Пример пользовательского модуля"
);

hello.onEnable(function (ctx) {
    ctx.message("Модуль включён");
});

hello.onTick(function (ctx) {
    if (!ctx.inGame()) return;
    // Здесь можно читать локального игрока и текущий мир.
});

hello.register();
```

После успешной загрузки модуль появится в категории `Misc`. Откройте меню
ModuleDLC и включите его.

## 3. Измените скрипт без перезапуска

Создание, изменение и удаление `.js`, `.java` или `.kt` в корне папки
`scripts` отслеживается во время игры. После сохранения файла он
перезагружается автоматически; вложенные папки не отслеживаются.

При ошибке загрузки она записывается в лог, а последняя успешно загруженная
версия этого файла продолжает работать. Удаление файла выключает и выгружает
его модули.

## Установка темы

Темы — отдельные JavaScript-файлы в `config/moduledlc/themes/`. Папка
создаётся автоматически. Скопируйте туда [пример DeepOcean.js](../examples/themes/DeepOcean.js),
откройте меню и выберите нужную тему в разделе `Theme` под `Binds`.
Изменения файлов тем применяются автоматически, выбранная тема сохраняется
между запусками игры.

## Поддерживаемые языки

- **JavaScript** — Rhino, файл `.js`, глобальный объект `api`.
- **Java** — `.java`-файл с классом, реализующим
  `dev.dlc.client.script.ScriptEntrypoint`. Для компиляции нужен JDK с
  `javac`; целевая версия — Java 21.
- **Kotlin** — `.kt`-файл с классом, реализующим
  `dev.dlc.client.script.ScriptEntrypoint`. В `PATH` должен быть доступен
  `kotlinc`; целевая версия JVM — 21.

Примеры всех трёх языков приведены в разделе [Языки скриптов](./languages.md).

## Отладка

Ошибки чтения, компиляции, загрузки и callbacks ModuleDLC записывает в лог
игры под `ModuleDLC/Scripts`. Для Java/Kotlin проверяйте также сообщения
компилятора в логе. Если новая версия не загрузилась, старый модуль остаётся
активным.

> Запускайте только доверенные скрипты: они исполняются внутри процесса игры
> и имеют доступ к API Minecraft-клиента.
