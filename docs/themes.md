# Темы интерфейса

JavaScript-файлы тем лежат отдельно от модулей в
`config/moduledlc/themes/`. Папка создаётся при запуске клиента; темы
перезагружаются автоматически после сохранения файла.

## Создание темы

Создайте `.js`-файл с вызовом `api.theme(id, name)`, задайте любые цвета и
завершите вызов `.register()`:

```javascript
api.theme("midnight", "Midnight")
    .color("background", "#0C1018")
    .color("surface", "#151C29")
    .color("accent", "#9B8CFF")
    .color("text", "#F2F0FF")
    .color("settingText", "#D7D2F5")
    .color("mutedText", "#928DAA")
    .color("error", "#FF6978")
    .register();
```

Для этой темы неуказанные цвета берутся из стандартной темы. Цвет принимает
формат `#RRGGBB` или `#RRGGBBAA` (альфа-канал в конце). ID должен состоять из
латинских букв, цифр, `.`, `_` или `-`, длиной до 48 символов. ID тем должен
быть уникальным между файлами; ID `default` зарезервирован.

## Цветовые роли

| Роль | Элемент |
| --- | --- |
| `background` | Фон меню |
| `surface` | Карточки модулей, поиска и профиля |
| `elevatedSurface` | Вложенные поверхности и поля выбора |
| `border` | Границы и разделители |
| `accent` | Активные состояния, переключатели и ползунки |
| `text` | Основной текст и значения настроек |
| `settingText` | Названия настроек |
| `mutedText` | Подсказки и второстепенный текст |
| `sectionText` | Заголовки разделов |
| `disabledText` | Неактивный текст |
| `error` | Ошибки модулей |
| `enabled` | Включённый модуль |
| `disabled` | Выключенные элементы управления |
| `hover` | Подсветка под курсором |
| `selected` | Выбранные элементы |
| `favorite` | Значок избранного |
| `sliderTrack` | Неактивная часть ползунка |
| `popupBackground` | Фон всплывающей палитры |
| `popupSurface` | Поверхности выпадающих списков |
| `popupBorder` | Граница всплывающих элементов |
| `white` | Светлый текст выпадающих списков |
| `shadow` | Затемнение за меню |

В разделе `Theme` каждая карточка показывает название и образцы цветов всех
ролей. Нажмите на карточку, чтобы применить тему. Выбранный ID сохраняется в
`config/moduledlc/active-theme.txt`. Тема `Default` всегда доступна; если
скрипт активной темы удалить, клиент вернётся к стандартной палитре.

Полный пример: [DeepOcean.js](../examples/themes/DeepOcean.js).
