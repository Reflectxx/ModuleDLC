# ModuleDLC Script API

ModuleDLC позволяет добавлять собственные клиентские модули из файлов
JavaScript, Java и Kotlin. Скрипты загружаются во время игры, а изменения
подхватываются автоматически.

## Кратко об API

Каждый скрипт может регистрировать модули через `api.module(id, name, category)`.
Модуль появляется в указанной категории и выключен до включения пользователем.
Допустимые категории: `Combat`, `Movement`, `Player`, `Visuals`, `UI` и `Misc`.
Если указать другое название, модуль не зарегистрируется и в чат будет отправлено
`this category not exists`.

JavaScript-файлы тем загружаются отдельно из `config/moduledlc/themes/`.
Через `api.theme(id, name)` тема задаёт цвета интерфейса и появляется в разделе
`Theme` под `Binds`; нажатие на карточку применяет тему. Подробности и список
цветовых ролей приведены в [разделе о темах](./themes.md).

Для модуля доступны callbacks:

| Callback | Когда вызывается |
| --- | --- |
| `onEnable(ctx)` | При включении модуля. |
| `onDisable(ctx)` | При выключении, выгрузке или ошибке в callback. |
| `onTick(ctx)` | Каждый клиентский тик, пока модуль включён. |
| `onFrame(ctx)` | Каждый кадр, пока модуль включён. |
| `onWorldRender(ctx, render)` | Во время рендера мира, пока модуль включён. |

`ctx` — объект `ScriptContext`. Он предоставляет `inGame()`, `player()`,
`world()`, `effects()`, `minecraft()`, `module()`, `message(text)`,
`sendChat(text)` и `setSprinting(value)`. Подробнее о чтении активных эффектов
и работе с другими игроками — в разделе [Игровые данные](./game-data.md).

## Команды клиента

Скрипт регистрирует команду вызовом `api.command(name, callback)` либо
`module.command(name, callback)` до `register()`. Команда вызывается с префиксом
`.`; callback получает контекст и массив строковых аргументов:

```javascript
api.command("hello", function (ctx, args) {
    ctx.message(args.length ? "Привет, " + args[0] : "Привет!");
});
```

`.hello "Имя игрока"` передаст один аргумент с пробелом. Кавычки и обратная
косая черта внутри кавычек поддерживаются. Распознанная команда не отправляется
на сервер; неизвестные команды остаются обычным сообщением чата. Имена команд
должны быть уникальными среди загруженных скриптов и содержать 1–48 букв,
цифр, `_` или `-`.

## Постоянное хранилище

`api.storage()` и `ctx.storage()` возвращают хранилище текущего скрипта:

```javascript
var storage = api.storage();
storage.set("targets", JSON.stringify(["minecraft:diamond_ore"]));
var targets = JSON.parse(storage.get("targets") || "[]");
```

Хранилище сохраняет строки между перезапусками в
`.minecraft/config/moduledlc/storage/`. Доступны `get(key)`, `set(key, value)`,
`remove(key)` и `keys()`. Значение ограничено 65 536 символами, ключ — 128
символами. Для объектов используйте `JSON.stringify`/`JSON.parse`.

## Поиск блоков и рендер мира

`ctx.findBlocks(blockId, radius)` возвращает позиции указанного блока в сфере
вокруг игрока. Радиус должен быть от 0 до 16 блоков; проверяются только уже
загруженные чанки, результат ограничен 4096 позициями. Вызывайте поиск не чаще,
чем нужно: полный скан может быть дорогим.

Для рисования добавьте модулю callback `onWorldRender(ctx, render)`. `render`
предоставляет `drawBlockOutline(pos, color)`, `drawBlockOutline(x, y, z, color)`,
`drawBox(aabb, color)` и координаты камеры `cameraX()`, `cameraY()`,
`cameraZ()`. Цвет задаётся целым ARGB, например `0xFFFF0000` для непрозрачного
красного.

Для HUD модуль до `register()` может создать элементы через
`hudText`, `hudRectangle` и `hudImage`; каждый элемент имеет `x()`, `y()`,
`setPosition(x, y)`, `setX(x)`, `setY(y)`, `draggable()` и `setDraggable(value)`.
Если у элемента разрешено перетаскивание, его координаты можно менять мышью
при открытом чате. Подробности и параметры создания описаны в разделе
[Модули и настройки](./modules-and-settings.md#hud-объекты).

## Важно

Скрипты выполняются с полномочиями процесса Minecraft. Запускайте только код,
которому доверяете. Скрипты имеют доступ к клиентским Java-объектам Minecraft;
это не даёт доступа к скрытым серверным данным и не обходит серверные правила.

Документация описывает API, реализованный сейчас. Подписки на произвольные
события Minecraft, бинды клавиш и отправка произвольных пакетов пока не
поддерживаются. Список текущих возможностей и ограничений — в
[жизненном цикле](./lifecycle.md).
